# 눌림목 스캐너

KRX 전 종목을 자동으로 스캔하여 **박스권 횡보 → 거래량 급증 돌파 → 눌림목** 구간에 있는 종목을 발굴합니다.
발굴 결과는 점수 순으로 정렬해 엑셀로 저장하고, 상위 종목의 일봉·주봉·월봉 차트 PNG를 자동 생성합니다.

---

## 매매 전략 개요

```
[박스권 1~2개월 횡보]
        ↓
[거래량 급증 (20일 평균 × 2.5배 이상) + 박스 상단 돌파]  ← 돌파 당일 매수 X
        ↓
[고점 형성 후 눌림목 (2~20% 하락)]  ← 여기서 매수 대기
        ↓
[박스 상단(신규 지지선) 부근 반등 확인]  ← 진입 시그널
        ↓
목표가: 박스 폭만큼 추가 상승
손절선: 박스 상단 하향 이탈
```

---

## 탐색 기준일

**오늘(실행일) 기준**, 각 단계의 탐색 구간:

| 단계 | 탐색 구간 | 설명 |
|---|---|---|
| 박스권 형성 | 최근 5~35 거래일 전 | 1~7주 전 구간의 가격 등락 범위 |
| 돌파 탐색 | **최근 10 거래일 이내** | 약 2주 안에 돌파한 종목만 포함 |
| 눌림목 확인 | **최신 종가 기준** | 실행일 당일 또는 직전 거래일 종가 |

> 매일 실행하면 그날 기준 최신 눌림목 종목을 뽑습니다.

## 스크리닝 조건 (전체 AND)

### 1단계 — 시총 사전 필터
| 조건 | 기본값 |
|---|---|
| 시가총액 최소 | **1,000억 원 이상** |

FDR(`StockListing`)으로 전 종목 시총을 일괄 조회 후 미달 종목 선제 제거 → 속도 향상.

### 2단계 — MA 추세 필터 (3개 시간프레임)

| 시간봉 | MA | 조건 | 기울기 최소 |
|---|---|---|---|
| 일봉 | MA60 | 횡보 또는 우상향 | -0.3% 이상 |
| 주봉 | MA20 | 우상향 | +0.1% 이상 |
| 월봉 | MA5 | 우상향 | +0.2% 이상 |

> 일봉 MA60은 완만한 하락도 허용 (바닥 탈출 초기 종목 포함 목적).

### 3단계 — 박스권 탐지

| 조건 | 기본값 | 설명 |
|---|---|---|
| 박스 기간 | 30 거래일 | 최근 1~2개월 횡보 구간 |
| 박스 허용 범위 | ±25% (총 ~50%) | 고점-저점 / 저점 ≤ 50% 이내 |

### 4단계 — 거래량 돌파

| 조건 | 기본값 | 설명 |
|---|---|---|
| 거래량 배수 | 2.5배 이상 | 돌파일 거래량 / 직전 20일 평균 |
| 돌파 탐색 범위 | 최근 10 거래일 | 너무 오래된 돌파 제외 |
| 돌파 기준 | 박스 상단 종가 돌파 | 종가 > 박스 고점 |

### 5단계 — 눌림목

| 조건 | 기본값 | 설명 |
|---|---|---|
| 눌림 최솟값 | 2% | 너무 얕은 눌림 제외 |
| 눌림 최댓값 | 20% | 추세 붕괴 수준 제외 |

눌림 = (돌파 후 고점 - 현재 종가) / 고점 × 100

## 유형 분류 (신규)

스크리닝 통과 종목은 자동으로 두 유형으로 분류됩니다.

| 유형 | 조건 | 엑셀 색상 |
|---|---|---|
| **바닥탈출** | 52주 저점 대비 +40% 이상 상승 **AND** 일봉 MA120 기울기 < 2% | 주황색 |
| **우상향** | 그 외 (기존 상승 추세 유지) | 초록색 |

- **바닥탈출**: 장기 하락 후 바닥에서 강하게 반등, 장기 MA는 아직 하락 중 (롯데케미칼 유형)
- **우상향**: 이미 상승 추세가 형성된 상태에서 눌림 후 재상승 (한미반도체 유형)

| 항목 | 배점 | 만점 조건 |

| 월봉 MA5 기울기 | 10점 | |

## 동작 흐름

```
1. FinanceDataReader (FDR)
   └─ 전 종목 시총 일괄 조회 → 1,000억 미만 사전 제거
   └─ pykrx: KRX 종목 코드 목록 수집

2. 병렬 스캔 (4 Worker, Sliding Window)
   └─ FDR(Naver Finance): 종목당 일봉 OHLCV 단일 요청 (~0.2초)
   └─ pykrx 폴백 (FDR 실패 시)

3. 5단계 필터 → 점수 계산 → 유형 분류 (바닥탈출 / 우상향)

4. 엑셀 저장 → 서식 적용 → (선택) 이메일 발송

5. 상위 10개 종목 차트 PNG 저장 (일봉 / 주봉 / 월봉)
```

## 실행

```bash
# 기본 실행 (KRX 전 종목, 시총 1,000억 이상)
python main.py

# KOSPI만 스캔, 거래량 조건 강화
python main.py --market KOSPI --vol-mult 4.0

# 특정 종목 3종 차트만 즉시 확인 (스캔 없이)
python main.py --chart-only 011170
```

### 주요 CLI 파라미터

| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `--market` | ALL | ALL / KOSPI / KOSDAQ |
| `--box-days` | 30 | 박스권 탐지 기간 (거래일) |
| `--box-tol` | 0.25 | 박스 허용 범위 (±25%) |
| `--vol-mult` | 2.5 | 돌파일 거래량 배수 |
| `--break-lookback` | 10 | 돌파 탐색 범위 (거래일) |
| `--pullback-min` | 0.02 | 눌림 최솟값 (2%) |
| `--pullback-max` | 0.20 | 눌림 최댓값 (20%) |
| `--min-cap` | 1000 | 시총 최소 (억원) |
| `--top-n` | 20 | 결과 저장 종목 수 |
| `--daily-ma` | 60 | 일봉 MA 기간 |
| `--weekly-ma` | 20 | 주봉 MA 기간 |
| `--monthly-ma` | 5 | 월봉 MA 기간 |
| `--chart-top` | 10 | 차트 저장 상위 종목 수 |
| `--no-chart` | — | 차트 생성 안 함 |
| `--chart-only` | — | 특정 종목 코드 — 차트만 생성 |

## 출력 파일

### 엑셀 — `output/눌림목스캐너_YYYYMMDD_HHMM.xlsx`

| 컬럼 | 설명 |
|---|---|
| 종목명 | 종목명 (하이퍼링크 → 네이버 금융) |
| 티커 | 6자리 종목코드 (하이퍼링크 → FnGuide) |
| 점수 | 종합 점수 (100점 만점) |
| **유형** | **바닥탈출(주황) / 우상향(초록)** |
| 현재가 | 최근 종가 (원) |
| 돌파일 | 박스 상단 돌파일 (MM/DD) |
| 돌파가 | 돌파일 종가 |
| 고점 | 돌파 이후 최고가 |
| 눌림(%) | 고점 대비 현재가 하락률 |
| 박스상단 | 박스권 저항선 (신규 지지선) |
| 박스하단 | 박스권 지지선 |
| 박스범위(%) | (박스상단 - 박스하단) / 박스하단 × 100 |
| 거래량배율 | 돌파일 거래량 / 20일 평균 거래량 |
| 시총(억) | 시가총액 (억원) |
| **52주저점대비(%)** | **52주 최저가 대비 현재가 상승률** |
| 일봉MA60기울기(%) | 최근 4봉 기준 MA60 변화율 |
| 주봉MA20기울기(%) | 최근 4주 기준 MA20 변화율 |
| 월봉MA5기울기(%) | 최근 3월 기준 MA5 변화율 |

### 차트 — `charts/{종목코드}_{종목명}/`

종목당 3종 PNG 저장:
- `{코드}_{이름}_일봉.png` — MA5·20·60, 박스권, 돌파 마커, 현재가(눌림%)
- `{코드}_{이름}_주봉.png` — MA5·10·20, 박스권
- `{코드}_{이름}_월봉.png` — MA3·5·10

## 이메일 발송

분석 완료 후 `SEND_EMAIL=true`이면 수신자 목록에 엑셀을 첨부하여 발송합니다.

- 제목: `[눌림목스캐너] YYYY-MM-DD HH:MM 스캔 완료 — N개 종목`
- 본문: 상위 10개 종목 점수·눌림률·거래량배율 요약
- 첨부: 결과 엑셀 파일

> Gmail 앱 비밀번호 발급: Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호
