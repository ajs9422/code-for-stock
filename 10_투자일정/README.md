# 투자일정 및 관련주 스캐너

향후 2개월 이내의 주요 투자 일정(경제 지표, 기업 이벤트, 테마 일정 등)을 수집하고, AI(Gemini)를 활용하여 관련 수혜주를 정리하여 엑셀로 저장합니다.

---

## 주요 기능

1. **투자 일정 수집**: 네이버 금융, 인베스팅닷컴 등 주요 금융 사이트에서 향후 2개월 내의 주요 일정을 수집합니다.
2. **관련주 분석**: 수집된 일정의 키워드를 기반으로 Gemini AI를 통해 시장의 관심이 쏠릴 수 있는 관련주 및 수혜 논리를 분석합니다.
3. **엑셀 리포트 생성**: 일정별로 정리된 데이터를 가독성 좋은 엑셀 파일로 저장합니다.
4. **자동화**: 주기적으로 실행하여 최신 일정을 업데이트할 수 있습니다.

---

## 동작 흐름

```
1. 일정 데이터 수집 (Crawl/Fetch)
   └─ 네이버 금융 증시일정 (IPO, 유상증자, 배당 등)
   └─ 주요 경제 캘린더 (금리 결정, CPI 등)
   └─ 테마성 일정 (컨퍼런스, 신제품 출시 등)

2. AI 분석 (Gemini API)
   └─ 각 일정별 중요도 판별
   └─ 일정 관련 핵심 키워드 추출
   └─ 관련 종목 및 테마 매칭
   └─ 투자 인사이트 도출

3. 데이터 정제 및 엑셀 저장
   └─ 날짜순 정렬
   └─ 일정/관련주/인사이트 컬럼 구성
   └─ 가독성 향상을 위한 엑셀 서식 적용
```

## 설치 및 환경 설정

### 1. 필수 라이브러리 설치

```bash
pip install pandas openpyxl requests beautifulsoup4 google-generativeai python-dotenv rich
```

### 2. 환경 변수 설정 (.env)

`10_투자일정/.env` 파일을 생성하고 아래 내용을 입력합니다.

```ini
GEMINI_API_KEY=your_gemini_api_key_here
```


## 활용 팁

- **일정 매매**: 중요한 일정이 다가오기 1~2주 전에 미리 관련주를 선취매하는 전략에 활용할 수 있습니다.
- **테마 분석**: 특정 시기에 집중된 일정을 통해 시장의 주도 테마를 미리 예측할 수 있습니다.
