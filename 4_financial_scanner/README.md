# 실적개선주 스캐너

전년(25A) 대비 올해(26E) 실적이 개선되면서 증권사 목표주가 대비 상승여력이 있는 종목을 자동으로 발굴합니다. 단순 이익 성장뿐 아니라 매출도 함께 성장하는 구조적 개선주를 선별합니다.

---

## 동작 흐름

```
1. FinanceDataReader
   └─ KRX 전종목 유니버스·업종·시가총액 수집
   └─ 시총 2,000억 미만 종목 제외 (MIN_MARKET_CAP)

2. FnGuide SVD_Main.asp (정적 HTML 파싱)
   └─ 매출·영업이익 25A(실적) / 26E(컨센서스 추정)
   └─ 분기 실적: 최근 보고 분기 + 차기 추정 분기 (Net Quarter 테이블)
   └─ 증권사 컨센서스 평균 목표주가
   └─ PER / 12M PER / BPS(26E) / ROE(26E)
   └─ 업종: FICS 세부 분류 우선, 없으면 KRX 광역 분류

3. 네이버 금융 모바일 API
   └─ 현재가 (JSON)

4. 네이버 금융 메인 페이지
   └─ 최신 분기 기준 PBR

5. 적정주가 산출 (S-RIM, 사경인 방식)
   └─ 적정주가 = BPS(26E) × ROE(26E) / r  (r = 8%)
   └─ BPS·ROE 데이터 없으면 증권사 목표주가로 폴백

6. 스크리닝 필터 (OR 방식)
   └─ 활성화된 조건 중 하나라도 만족하면 후보군 편입

7. 종합점수 산출 (0~100점) → 내림차순 정렬

8. 엑셀 저장 → 서식 적용 → highlight_excel (AND조건 시트) → (선택) 이메일 발송

9. DART API 후처리 (DART_API_KEY 설정 시)
   └─ 필터 통과 종목만 FCF 수집 → PFR 산출
   └─ TTM FCF = 연간 FCF − Q1전년 FCF + Q1당년 FCF
```

## 스크리닝 조건 (OR — 하나라도 만족 시 편입)

| # | 조건 | 기본값 | 설명 |
|---|------|--------|------|
| ① | 영업이익 절대 성장 | 필수 | 26E 영업이익 > 25A 영업이익 |
| ② | 영업이익증가율 최소 | 20% | 시장 평균(5~10%) 대비 확실한 개선 |
| ③ | 매출증가율 최소 | 10% | 매출도 함께 성장해야 구조적 개선으로 인정 |
| ④ | 상승여력 최소 | 15% | 적정주가 또는 증권사 목표주가 대비 |
| ⑤ | PSR 상한 | 2.0배 | 시가총액 ÷ 26E 매출 (낮을수록 저평가) |
| ⑥ | PER 상한 | 25.0배 | 주가 ÷ 주당순이익 |

> `config.py`에서 각 임계값 조정 가능. `None`으로 설정하면 해당 조건 비활성화.

## 종합점수 산출 방식 (0~100점)

각 지표를 합리적 상·하한으로 clip 후 0~100 선형 정규화, 가중 합산합니다.

| 지표 | 가중치 | 방향 | 정규화 범위 |
|------|--------|------|-------------|
| 영업익증가율(%) | 25% | 높을수록↑ | 0 ~ 500% |
| 상승여력1(%) | 10% | 높을수록↑ | 0 ~ 80% (S-RIM 적정주가 기준) |
| 상승여력2(%) | 10% | 높을수록↑ | 0 ~ 80% (증권사 목표주가 기준) |
| 매출증가율(%) | 20% | 높을수록↑ | 0 ~ 100% |
| PSR | 10% | 낮을수록↑ | 0 ~ 5배 |
| PER / 12M PER | 25% | 낮을수록↑ | 5 ~ 40배 |

> 12M PER 없는 종목은 PER로 대체. 둘 다 없으면 0점 처리.

## 엑셀 출력 구조

### 시트 구성

| 시트 | 내용 |
|------|------|
| 종합 | 전체 통과 종목, 종합점수 내림차순 (분기 컬럼 제외 — 가로 폭 최소화) |
| 종합(분기포함) | 종합과 동일하나 분기 실적 컬럼 12개 포함 (상세 분석용) |
| ★AND조건 | 상승여력2·PER·영업익증가율 조건을 동시 충족하는 종목 |
| ★메가테마 (테마별) | config.py `MEGA_THEMES`에 정의된 테마 (조선·방산·로봇·2차전지·AI·반도체·원전·전력망 등) |
| 업종별 (약 27개) | 업종별 분리, 종합점수 내림차순 |
| ★눌림목 | 7_눌림목_스캐너 최신 결과 자동 병합 |

> **종합** 시트는 핵심 지표만 담아 한눈에 보기 편하게, **종합(분기포함)** 시트는 분기별 매출·영업이익 추이까지 확인할 때 사용합니다.

### 컬럼 구성

| 컬럼 | 설명 |
|------|------|
| 종목명 | 종목명 (하이퍼링크 → 네이버 금융) |
| 티커 | 6자리 종목코드 (하이퍼링크 → FnGuide) |
| 업종 | FICS 업종 분류 |
| 종합점수 | 0~100점 |
| 현재가 | 네이버 모바일 API 기준 |
| 적정주가 | S-RIM 산출값 (BPS·ROE 없으면 증권사 목표주가) |
| 상승여력1(%) | (적정주가 − 현재가) / 현재가 × 100 |
| 증권사목표주가 | FnGuide 컨센서스 평균 |
| 상승여력2(%) | (증권사목표주가 − 현재가) / 현재가 × 100 |
| 25년매출(억) | 2025년 실적(A) |
| 26년매출E(억) | 2026년 컨센서스 추정(E) |
| 매출증가율(%) | (26E − 25A) / \|25A\| × 100 |
| 25년영업익(억) | 2025년 실적(A) |
| 26년영업익E(억) | 2026년 컨센서스 추정(E) |
| 영업익증가율(%) | (26E − 25A) / \|25A\| × 100 |
| NQ25매출(억) | 최근 보고 분기의 전년 동기 매출 (실행일 기준 자동 분기명) |
| NQ26매출(억) | 최근 보고 분기 매출 |
| NQ매출YoY(%) | 최근 분기 매출 전년 동기 대비 증가율 |
| NQ25영업익(억) | 최근 보고 분기의 전년 동기 영업이익 |
| NQ26영업익(억) | 최근 보고 분기 영업이익 |
| NQ영업익YoY(%) | 최근 분기 영업이익 전년 동기 대비 증가율 |
| NQ+1 25매출(억) | 차기 추정 분기의 전년 동기 매출 |
| NQ+1 26E매출(억) | 차기 추정 분기 매출 컨센서스 |
| NQ+1 매출YoY(%) | 차기 분기 매출 전년 동기 대비 증가율 |
| NQ+1 25영업익(억) | 차기 추정 분기의 전년 동기 영업이익 |
| NQ+1 26E영업익(억) | 차기 추정 분기 영업이익 컨센서스 |
| NQ+1 영업익YoY(%) | 차기 분기 영업이익 전년 동기 대비 증가율 |
| PER | Trailing PER (최근 결산 EPS 기준) |
| 12M PER | 12개월 Forward PER |
| 12M PER/PER | Forward/Trailing 비율 |
| PSR | 시가총액(억) ÷ 26E 매출(억) |
| PBR | 최신 분기 BPS 기준 |
| PFR | 시가총액(억) ÷ TTM FCF(억) — DART API 키 설정 시 활성화 |

> 분기 컬럼명은 실행일 기준으로 자동 계산됩니다.  
> 예) 2026년 5월 실행 → `1Q25매출(억)` / `1Q26매출(억)` / `2Q25매출(억)` / `2Q26E매출(억)`

## 업종 강제 지정 (`SECTOR_OVERRIDES`)

FnGuide FICS 분류를 무시하고 특정 종목을 원하는 업종 시트에 강제 편입할 수 있습니다.

```python
# config.py
SECTOR_OVERRIDES: dict[str, str] = {
    "020150": "2차 전지",   # 롯데에너지머티리얼즈
    "006400": "2차 전지",   # 삼성SDI
    ...
}
```

## 주요 설정 (`config.py`)

| 항목 | 기본값 | 설명 |
|------|--------|------|
| `ACTUAL_YEAR` | 2025 | 실적 기준 연도 (25A) |
| `ESTIMATE_YEAR` | 2026 | 추정 기준 연도 (26E) |
| `MIN_MARKET_CAP` | 2,000억 | 시총 최소 필터 |
| `TEST_STOCKS` | None | 상위 N개만 테스트 (`None` = KRX 전체) |
| `SRIM_REQUIRED_RETURN` | 8% | S-RIM 기대수익률 (r) |
| `DELAY` | 0.3초 | 종목 간 크롤링 딜레이 |
| `TIMEOUT` | 15초 | HTTP 요청 타임아웃 |

## 소요 시간

| 대상 | 소요 시간 |
|------|----------|
| KRX 전체 (~2,600종목) | 약 40~60분 |
| 시총 2,000억 이상 (~600종목) | 약 10~15분 + DART 후처리 10~20분 |
| TEST_STOCKS=50 | 약 1~2분 |

> 종목당 FnGuide + 네이버 2회 요청 + 0.3초 딜레이.  
> DART API 후처리는 필터 통과 종목(수백 개)에만 적용되며 종목당 최대 2회 요청.

## 이메일 발송

분석 완료 후 `SEND_EMAIL=true`이면 수신자 목록에 엑셀을 첨부하여 발송합니다.

- 제목: `[실적개선주] YYYY-MM-DD HH:MM 스캔 완료 — N개 종목`
- 본문: 분석 결과 요약, 상위 10개 종목, 엑셀 구성 설명, 스크리닝 조건, 동작 방식
- 첨부: 하이라이팅·AND조건 시트가 적용된 결과 엑셀 파일 (`_hl.xlsx`)
