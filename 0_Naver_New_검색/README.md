# 네이버 뉴스 검색기

키워드를 입력하면 네이버 뉴스 최신순 1페이지를 수집하여 제목·날짜·링크를 터미널에 출력하고 엑셀로 저장합니다.

---

## 동작 흐름

```
1. 키워드 입력
   └─ 네이버 뉴스 검색 (최신순, 1페이지)

2. Selenium으로 페이지 수집
   └─ 구 구조: a.news_tit
   └─ 신 구조: span.sds-comps-text-type-headline1
   └─ 중복 URL 제거

3. 날짜 3단계 보정 (ymd_best)
   └─ 1순위: 기사 URL에서 날짜 패턴 추출
   └─ 2순위: 뉴스 카드 텍스트에서 날짜 토큰 파싱
              (YYYY.MM.DD / MM.DD / N분 전 / N시간 전 / 어제 / 오늘 등)
   └─ 3순위: 기사 본문 페이지 메타태그 / 날짜 텍스트 직접 파싱

4. 결과 출력
   └─ 터미널: 번호 / 제목 / 날짜 / 링크
   └─ 엑셀: {키워드}_1page.xlsx
```

---

## 엑셀 출력 구조

| 컬럼 | 설명 |
|---|---|
| 제목 | 뉴스 기사 제목 |
| 날짜 | YYYY-MM-DD 형식 (3단계 보정 결과) |
| 링크 | 기사 원본 URL |

---

## 설치

```bash
pip install selenium webdriver-manager beautifulsoup4 requests pandas openpyxl colorama
```

---

## 실행

```bash
python naver_news_selenium_0914.py
```

실행 후 검색어를 입력하면 자동으로 수집·저장합니다.

---

## 소요 시간

| 항목 | 내용 |
|---|---|
| 수집 범위 | 최신순 1페이지 (약 10~15건) |
| 날짜 보정 | URL·텍스트로 해결 시 즉시 / 본문 메타 조회 시 건당 ~7초 추가 |
| 헤드리스 | 기본값 True (브라우저 창 미표시) |
