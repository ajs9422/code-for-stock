# 뉴스기사 인사이트 — 호재성 종목 · 공급망 연관 종목 발굴기

7개 소스(네이버 경제/증권·4개 금융 RSS·KRX 공시)에서 최근 **36시간 이내** 뉴스를 자동 수집하고,  
Gemini AI로 **호재 종목과 악재 종목을 분리**하여 직접수혜 → 공급망 → 간접수혜 체인으로  
관련 종목을 발굴하는 투자 인사이트 도구입니다.

단순한 종목 언급 추출이 아니라, 뉴스가 **왜** 호재인지, 어떤 **공급망 종목**까지 파급되는지를  
AI가 추론하여 엑셀 4개 시트로 정리합니다.

---

## 동작 흐름

```
1. 뉴스 수집 (7개 소스 병렬, 중복 URL 제거 → 총 ~130건)
   ├─ 네이버 경제 헤드라인 (sid1=101) : 36시간 이내, 최대 15건/일 (오늘·어제 페이지)
   ├─ 네이버 증권 섹션    (sid2=258)  : 36시간 이내, 최대 10건/일 (오늘·어제 페이지)
   ├─ 한국경제 RSS                    : 최대 20건
   ├─ 연합뉴스 경제 RSS               : 최대 20건
   ├─ 매일경제 RSS                    : 최대 20건
   ├─ 서울경제 RSS                    : 최대 20건
   └─ KRX KIND 공시 (폭등전조)        : 최대 15건
       └─ 대규모계약·지분변동·최대주주변경·합병·자사주·수주 등 핵심 공시만 필터

2. 기사 본문 추출 (3단계 폴백, 병렬 10건 동시)
   ├─ newspaper3k
   ├─ requests + 네이버 본문 셀렉터 (#dic_area, .newsct_article, #articeBody)
   └─ og:description 메타태그 (최후 수단)

3. Gemini AI 개별 분석 (gemini-2.5-flash, 병렬 5건 동시)
   ├─ [사전 필터] 제목 기반으로 연예·스포츠·날씨 등 투자 무관 기사 스킵
   ├─ 투자관련 여부 판단 → false 이면 스킵
   ├─ 중요도 3점 미만 AND 단기폭발력 5점 미만 → 스킵
   │
   ├─ [핵심1] 호재/악재 종목 분리
   │   ├─ 직접수혜종목   : 기사가 명확히 호재인 상장사 (악재 종목 포함 금지)
   │   ├─ 간접수혜종목   : 공급망·경쟁구도·정책 수혜로 오를 수 있는 연관사 (최소 2개 추론)
   │   │    예) 반도체 수요 급증 → 반도체 장비주·소재주
   │   │        전기차 배터리 수주 → 양극재·음극재·분리막 소재주
   │   ├─ 공급망연관종목 : 직접수혜종목의 납품업체·고객사 중 상장사 (1차 공급망 체인)
   │   └─ 부정영향종목   : 이 뉴스로 악재를 받을 상장사
   │
   ├─ [핵심2] 7대 폭등 전조 시그널 탐지
   │   ① 제도/정책 빅뱅  ② 독점/최초/단독 계약  ③ 실적 서프라이즈
   │   ④ 대규모 지분 변동  ⑤ 신사업/기술 돌파  ⑥ 수급 변화  ⑦ M&A/합병/분할
   │
   └─ [핵심3] 가치주 시그널 탐지
       └─ 적자→흑자 전환, 저PER+실적 급증, 목표가 대폭 상향

4. Gemini AI 합성 분석 (전체 결과 기반, 1회)
   ├─ 유망 섹터/테마 Top5 (직접수혜·간접수혜 종목 분리 포함)
   ├─ 주목 종목 Top10 (발굴 우선순위):
   │   ① 폭등 후보    : 단기폭발력 7↑ OR 폭등전조유형 보유
   │   ② 공급망연관주 : 직접수혜종목의 핵심 납품업체·고객사
   │   ③ 간접 수혜주  : AI 추론 발굴 (공급망·테마 연관)
   │   ④ 가치주       : 실적 턴어라운드, 저평가
   │   ⑤ 복수 언급   : 여러 기사에서 반복 등장한 호재 종목
   ├─ 악재 경고 종목 Top5 (부정영향종목 중 복수 언급 위주)
   └─ 시장 방향성 요약 + 투자 주의사항

5. 엑셀 저장 (5개 시트) + 서식 적용 → (선택) 이메일 발송
   ├─ Sheet1 종목뉴스      : 호재 기사 (발굴점수 = 단기폭발력×2 + 중요도 순)
   ├─ Sheet2 투자인사이트  : 합성 분석 4섹션
   ├─ Sheet3 시장일반      : 거시경제·정책 뉴스
   ├─ Sheet4 종합          : 직접수혜종목 × 4_financial_scanner 종합 시트 매칭 (분기 제외)
   └─ Sheet5 종합(분기포함): 종합 + 분기별 YoY 컬럼
```

## 엑셀 출력 구조

### Sheet1 — 종목뉴스

호재성 기사를 발굴점수(단기폭발력×2 + 중요도) 순으로 정렬합니다.

| 컬럼 | 설명 |
|---|---|
| 뉴스제목 | 기사 제목 |
| 출처 | 네이버경제 / 네이버증권 / 한국경제 / 연합뉴스 / KRX공시 등 |
| 핵심이슈 | 투자자 관점 한 문장 요약 |
| 뉴스방향성 | 긍정(연초록) / 부정(연주황) / 중립 |
| 직접수혜종목 | 이 뉴스가 호재인 상장사 (하이퍼링크 → 네이버 금융) |
| 간접수혜종목 | 공급망·정책 수혜 연관 상장사 (하이퍼링크) |
| 공급망연관종목 | 직접수혜종목의 납품업체·고객사 |
| 부정영향종목 | 악재를 받을 상장사 |
| 투자호재성격 | 제도정책 / 독점최초 / 실적서프라이즈 / 지분변동 / 신사업기술 / 수급변화 / M&A |
| 폭등전조유형 | 7대 폭등 시그널 해당 시 유형명 (주황 강조) |
| 단기폭발력 | 1~10 (7↑ 연초록, 4~6 연노랑) |
| 숨은수혜주_여부 | AI가 추론한 간접 수혜주 포함 여부 |
| 가치주신호 | 실적 턴어라운드·저평가 감지 시 True (연파랑 강조) |
| 인사이트 | 직접·간접 수혜주 관점을 모두 포함한 주가·수급 영향 분석 |
| 중요도 | 1~10 (3↓ 수집 제외) |
| 원본링크 | 기사 링크 ("링크" 하이퍼링크) |

---

### Sheet2 — 투자인사이트 (핵심 시트)

합성 분석 결과를 4개 섹션으로 배치합니다.

**섹션A — 시장 방향성** (진남색 헤더)

| 컬럼 | 설명 |
|---|---|
| 시장 방향성 요약 | 현재 시장 전반 흐름 요약 |
| 투자 주의사항 | 현재 시장 리스크 요인 |

**섹션B — 유망 섹터/테마 Top5** (청록 헤더)

| 컬럼 | 설명 |
|---|---|
| 순위 | 중요도 기준 |
| 섹터/테마 | 섹터 또는 투자 테마명 |
| 투자 근거 | 왜 유망한지 투자 관점 설명 |
| 핵심 촉매 | 이 섹터/테마를 움직이는 핵심 이슈 |
| 직접수혜종목 | 이 테마의 직접 수혜 상장사 |
| 간접수혜종목 | 공급망·정책 연관 간접 수혜 상장사 |
| 중요도 | 1~10 (7↑ 연초록) |

**섹션C — 주목 종목 Top10** (청록 헤더)

| 컬럼 | 설명 |
|---|---|
| 종목명 | 주목 종목명 |
| 발굴유형 | 폭등후보 / 공급망연관 / 간접수혜 / 가치주 / 복수언급 |
| 공급망 위치 | 직접수혜 / 1차공급망 / 간접수혜 / 정책수혜 |
| 호재 근거 | 구체적인 호재 내용 — 어떤 뉴스가 왜 호재인지 |
| 기사 언급횟수 | 수집 기사 중 언급 횟수 |
| 리스크 | 단기 리스크 요인 |

**섹션D — 악재 경고 종목** (진주황 헤더)

| 컬럼 | 설명 |
|---|---|
| 종목명 | 악재 영향 종목명 |
| 악재 내용 | 구체적인 악재 내용 |
| 영향 강도 | 1~10 (7↑ 주황 강조) |

특정 종목 없이 금리·환율·정책·거시경제 흐름을 다루는 기사입니다.

| 컬럼 | 설명 |
|---|---|
| 뉴스제목 | 기사 제목 |
| 출처 | 뉴스 소스 |
| 핵심이슈 | 투자자 관점 요약 |
| 뉴스방향성 | 긍정 / 부정 / 중립 |
| 투자호재성격 | 재료 유형 |
| 단기폭발력 | 1~10 |
| 인사이트 | 시장 파급력 분석 |
| 중요도 | 1~10 |
| 원본링크 | 기사 링크 |

### Sheet4 — 종합

Sheet1(종목뉴스)의 직접수혜종목을 `4_financial_scanner/output` 최신 파일의 **종합** 시트와 매칭하여 재무 현황을 정리합니다 (분기 컬럼 제외).

| 컬럼 | 설명 |
|---|---|
| 관련뉴스 | 해당 종목이 언급된 뉴스 제목 |
| 종목명 | 종목명 (하이퍼링크 → 네이버 금융) |
| 티커 | 6자리 종목코드 (하이퍼링크 → FnGuide) |
| 업종 | KRX 업종 분류 |
| 종합점수 | 실적 종합 점수 |
| 현재가 / 적정주가 | 가격 및 목표가 |
| 상승여력1(%) / 상승여력2(%) | 20%↑ 연초록 하이라이트 |
| 매출·영업익 증가율 | 영업익증가율 30%↑ 연노랑 하이라이트 |
| PER / 12M PER | PER 12 미만 → 연파랑 하이라이트 |
| PBR / PSR / PFR | 밸류에이션 지표 |

## 환경 변수 (.env)

```ini
GEMINI_API_KEY=...    # Google AI Studio에서 발급

# 이메일 발송 (Gmail)
GMAIL_USER=yourname@gmail.com
GMAIL_APP_PASSWORD=...     # Gmail 앱 비밀번호 (2단계 인증 필요)

# 수신자
NOTIFY_EMAIL=to@example.com
NOTIFY_EMAIL_WIFE=to2@example.com
NOTIFY_EMAILS_EXTRA=a@x.com;b@x.com   # 추가 수신자 (세미콜론 구분)

# 이메일 발송 여부 (true/false)
SEND_EMAIL=false
```

## 이메일 발송

분석 완료 후 `SEND_EMAIL=true`이면 수신자 목록에 엑셀을 첨부하여 발송합니다.

- 제목: `[뉴스 인사이트] YYYY-MM-DD HH:MM 분석 완료 — 주목 N개 / 직접수혜 M개`
- 본문: 주목 종목 목록, 악재 경고 종목, 엑셀 5개 시트 구성 설명, 동작 방식 요약
- 첨부: 결과 엑셀 파일

> Gmail 앱 비밀번호 발급: Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호
